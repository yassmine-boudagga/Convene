# Backend

Node.js / Express API for Convene.

## What it does

- Authentication and refresh-token handling
- Meeting lifecycle and LiveKit room management
- Notification delivery and WebSocket synchronization
- File upload and recording finalization
- Admin endpoints and static admin UI

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Environment

Create `backend/.env` from `backend/.env.example` and fill in your local values.
